# Engineering audits

English · [简体中文](README.zh-CN.md)

Periodic engineering maturity audits. Each audit scores 12 dimensions × 4 checks from evidence in the repository, records the six stress tests, and lists findings with IDs that later audits follow up. Run one at the end of every roadmap phase or on request. The maintainer keeps the rubric and raw review materials outside the source checkout.

Findings that need work are tracked as roadmap tasks or issues; the audit record links to them.
