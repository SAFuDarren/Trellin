# Engineering audits

English · [简体中文](README.zh-CN.md)

Periodic engineering maturity audits. Each audit scores 12 dimensions × 4 checks from evidence in the repository, records the six stress tests, and lists findings with IDs that later audits follow up. Run one at the end of every roadmap phase, or when asked, with the project skill in `.claude/skills/engineering-audit/` (in Claude Code: "run an engineering audit").

Findings that need work are tracked as roadmap tasks or issues; the audit record links to them.
