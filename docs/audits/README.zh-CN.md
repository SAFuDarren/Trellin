# 工程审计

[English](README.md) · 简体中文

定期的工程成熟度审计。每次审计根据仓库里的实际证据，给 12 个维度 × 4 项检查打分，记录六项压力测试的结果，并给每条发现编号，供以后的审计跟进。每个路线图阶段结束时做一次，或者按需进行。维护者将自查标准和审计原始材料保存在软件源码目录外。

需要处理的发现会作为路线图任务或 issue 跟踪，审计记录里会链接过去。
