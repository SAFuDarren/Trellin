# 课题开始与定理录入

打开绑定本机 PostgreSQL 的工作台。两个入口都可以在课题还没有命题时使用。

## 与 AI 梳理

点「和 AI 梳理资料」，填写标题、方向和想弄清的问题，粘贴需要整理的文字，或选择支持的文本文件。选择正在本机 Ollama 服务中可用的模型，然后生成草稿。Trellin 只把本次提交的文字交给本机模型。

候选项会引用对应的原文。逐条查看提出的定义、假设和定理及其形式化，决定哪些可以进入起始依据，并填写本人的审查信息。形式化尚有歧义的条目可以补清楚后再采纳，也可以先排除。草稿可以重新打开。AI 提取的结果需要你亲自确认，之后的证明推进仍绑定你确认的命题和授权。

模型清单来自本机 Ollama 服务。使用前请确保本机服务正在运行，而且已有可处理文本的模型。模型选择只作用于当前请求。请求沿用现有资料梳理流程留痕。

## 添加定理

点「手动添加定理」，填写自然语言陈述和精确的 Lean 命题，再选择它的用途。

- **已有定理**保存为库草稿。可填写来源，之后查看保存的原文和 Lean 陈述并确认该版本。确认形式化记录你对陈述含义的判断，已核验的证明另有证据记录。
- **待证明命题**保存你确认的研究目标。直接录入自包含的 Lean 命题时，请把明示的前提写入命题的绑定变量并确认。确认后的目标出现在命题列表。Lean 核验以及额外项目依据的确认沿用现有流程。

本地模型不可用时，仍可添加和审查定理。
