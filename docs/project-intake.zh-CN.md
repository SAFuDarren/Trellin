# 课题开始与定理录入

打开绑定本机 PostgreSQL 的工作台。两个入口都在项目图谱标题栏的 **+** 按钮（「添加到项目」）里，课题还没有命题时也能使用。

## 导入论文、笔记或代码

点「+ → 论文、笔记或代码…」，或把文本、Markdown、TeX 或 Lean 文件直接拖到项目图谱上。还没有课题的项目会在图谱中间显示拖入区，并提供「选择文件…」和「新定理…」。打开时只有「选择文件…」和「改为粘贴文本」；拖到图谱上的文件会直接放进来。放进材料后，窗口显示文件名、大小和由哪个模型读取，点「整理」即可发送。读不了的文件，例如 PDF 或超过 18 KB 的文件，会在窗口里说明原因。

标题取文件名，研究目标用默认值，模型默认用这个项目上次用过的，没有就用第一个可用的。「高级选项」按项目记住展开状态，里面可以改标题、模型、研究目标和正文。没有可用模型时，窗口会说明，并链接到「Team → 运行环境 → 模型连接」。

本机 Ollama 模型在这台 Mac 上读取私有材料。一个项目第一次用已连接的云端模型导入时，窗口会问一次是否允许这个模型读取本项目导入的材料。Trellin 会记下是谁、在什么时候允许的，之后用这个模型导入不再询问。「Team → 运行环境」会在连接旁显示「已允许用于这个项目的导入」，点「撤销」后下次导入会再问。移除或更改连接也会终止许可。只发送可以交给该服务商的材料。

候选项会引用对应的原文。逐条查看提出的定义、假设和定理及其形式化，决定哪些可以进入起始依据，并填写本人的审查信息。形式化尚有歧义的条目可以补清楚后再采纳，也可以先排除。草稿可以重新打开。AI 提取的结果需要你亲自确认，之后的证明推进仍绑定你确认的命题和授权。

### 连接模型

点「Team → 运行环境 → 模型连接 → 添加连接」。从 Trellin 检测到的已安装程序中选择 Codex 或 Claude Code。若提示登录，先通过对应命令行工具登录，再检查一次。可以从列表选模型，也可以沿用服务商默认值。已安装的 Codex 支持读取模型列表时，Trellin 会显示返回的选项。Claude Code 提供模型系列选项，具体可用性取决于账号。也可以输入账号支持的模型标识。每个模型单独保存为连接，可在资料梳理和证明任务中选择。点「测试连接」会用一条简短的示例请求检查账号能否使用它。

在「工作台」或「对话」中，也可从模型菜单点「管理模型连接」。添加后关闭弹窗，再选择模型。原会话和草稿会保留。

直连 OpenAI 或 Anthropic API 时，选择对应 API 入口，填写模型标识和自己的 API 密钥。API 密钥保存在 macOS 钥匙串。连接列表只显示你添加的模型。

「测试连接」发送一条固定请求，内容与课题无关。「移除连接」后，该连接不会再接收新请求，排队的证明任务仍绑定原连接。要换连接，先停止正在等待的任务，再用新连接重新授权。已有模型结果和核验记录留在项目中。使用本机模型时先启动 Ollama，并确保已下载支持文本的模型。

## 新定理

点「+ → 新定理…」，填写自然语言陈述和精确的 Lean 命题，再选择它的用途。

- **已有定理**保存为库草稿。可填写来源，之后查看保存的原文和 Lean 陈述并确认该版本。确认形式化记录你对陈述含义的判断，已核验的证明另有证据记录。
- **待证明命题**保存你确认的研究目标。直接录入自包含的 Lean 命题时，请把明示的前提写入命题的绑定变量并确认。确认后的目标出现在命题列表，也会作为独立目标显示在当前项目的证明画布上，保留正在查看的命题。点击画布上的其他目标才会打开它的证明图。在 Mac App 的「文件 → 新建项目」可另建项目。Lean 核验以及额外项目依据的确认沿用现有流程。

本地模型不可用时，仍可添加和审查定理。
