# Name and logo policy

English · [简体中文](TRADEMARKS.zh-CN.md)

The code is open under the Apache License 2.0, and you may use, modify and redistribute it. The **Research Multiplier** name and logo are different: they tell people which version is the official one, so they are not covered by the code license (Apache License 2.0, section 6).

## You may, without asking

- Say that your work uses, extends or is compatible with Research Multiplier, for example "a plugin for Research Multiplier" or "built on Research Multiplier".
- Refer to the project by name in articles, papers, talks, teaching material and documentation.
- Distribute unmodified official releases under the name.
- Use the name for plugins and extensions in the form "*Your Name* for Research Multiplier", as long as it is clear they are not made by the project.

## Please ask first

- Naming a modified version, fork or hosted service "Research Multiplier", or a name easily confused with it.
- Using the logo in a way that suggests endorsement, partnership or official status.
- Using the name in a product, company or domain name.

A fork is welcome. Give it a different name and say that it is based on Research Multiplier.

## Contact

Open an issue in the project repository, or contact the maintainer listed there.

This policy may be updated as the project grows. It does not limit any rights granted by the code license.
